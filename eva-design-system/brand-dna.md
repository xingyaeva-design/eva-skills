# Brand DNA — Eva Lan 的品牌基因

> 所有场景、所有页面共享的底层规范。无论哪种设计风格，都不能违背此文件的核心约束。

---

## 🎨 核心配色

| 色名 | 色值 | 角色 | 主要用途 |
|------|------|------|---------|
| 月白 | `#F5F4F0` | 主背景 | 页面底色 |
| 浅灰底 | `#E8E6E0` | 次级背景 | 卡片底、分隔区块 |
| 深灰底 | `#DDDAD3` | 三级背景 | hover 状态、更深的层次 |
| 烟绿 | `#8A9E92` | 主色 | 标签、eyebrow、border、icon |
| 深烟绿 | `#5E7A6A` | 主色深版 | hover、次级标题、强调文字 |
| 暖金 | `#C4A882` | 点缀色 | 数字、年份、badge、引用边框、装饰线、高亮下划线 |
| 沙金 | `#BEB5A2` | 辅助装饰 | 最轻的分隔线、次级装饰元素 |
| 深墨 | `#2E2820` | 正文 | 标题、正文主色 |
| 中灰棕 | `#4e4840` | 次级正文 | 说明文字、副标题 |
| 哑光棕 | `#A09688` | 辅助文字 | meta、注释、时间戳 |

### 色彩比例原则
月白底 55% · 烟绿系 20% · 深墨文字 15% · 暖金点缀 8% · 沙金装饰 2%

### 暖金使用规则（重要）
暖金是点缀色，不是主色。具体使用场景：
- 深色背景（`#2C2C28`）里的年份、时间标签
- 数字大字（stat block、编号）
- badge/tag（与烟绿 badge 搭配使用，形成层次）
- 引用块左边框（观点类/金句类，方法论类用烟绿）
- 正文高亮下划线 `background: linear-gradient(to top, rgba(196,168,130,0.35) 45%, transparent 45%)`
- 装饰分隔线（强调级别，介于烟绿和沙金之间）

**禁止**：暖金做大面积背景、暖金做正文颜色、暖金和烟绿同时出现在同一个元素上

## 🌑 深色场景规范

深色用于**打破节奏**，不做整页主色调。

| 规则 | 说明 |
|------|------|
| 深色块占比 | 单页面最多 30%，用于时间线、全幅引用、强调 section |
| 深色背景色 | `#2C2C28`（带暖意的近黑，不用纯黑） |
| 深色文字色 | `#F0EDE6`（暖白，不用纯白） |
| 深色次级文字 | `rgba(240,237,230,0.5)` |
| 深色分隔线 | `rgba(190,181,162,0.12)` |
| 深色 eyebrow | 烟绿 `#8A9E92` |
| 深色年份/数字 | **暖金** `#C4A882`（深色场景专用，浅色场景用烟绿） |
| 深色装饰大字 | `color: var(--sand); opacity: 0.12` |

## 🔤 字体基因

### 核心原则
- **标题与正文都用衬线** — 整体温柔、有质感，不割裂
- **英文 Cormorant Garamond，中文 Noto Serif SC** — 气质一致
- **字号对比极端** — 大的要很大，小的要真的小
- **字重克制** — 标题 600，正文 300/400，不用 700+

### 字体栈（含 Fallback）

```css
--font-en: 'Cormorant Garamond', Georgia, serif;
--font-cn: 'Noto Serif SC', 'Songti SC', 'SimSun', serif;
```

### 字体池

| 场景 | 字体 | 字重 | 备注 |
|------|------|------|------|
| 英文标题/大字 | Cormorant Garamond | 300–600 | 品牌第一字体 |
| 英文标题斜体 | Cormorant Garamond italic | 300–400 | 软化、增加层次 |
| 辅助标签/eyebrow | sans-serif 系统字体 | — | `letter-spacing: 0.16em` + uppercase |
| 中文标题/正文 | Noto Serif SC | 400/500 | 与 Cormorant 气质匹配 |
| 中文细节/辅助 | Noto Serif SC | 300 | 轻盈感 |

### 字号系统（fluid sizing）
- Hero 大标题：`clamp(3rem, 7vw, 5.5rem)`
- Section 标题：`clamp(1.5rem, 3.5vw, 2.4rem)`
- 卡片标题：`1.2rem ~ 1.5rem`
- 正文：`15px ~ 16px`
- 辅助文字：`0.78rem ~ 0.85rem`
- 大装饰数字：`clamp(3rem, 8vw, 7rem)` + `opacity: 0.04~0.12`
- Eyebrow/标签：`0.65rem ~ 0.72rem` + `letter-spacing: 0.16em`

## ✨ 气质关键词

设计出来的东西应该让人觉得：

- **温柔又冷静** — 不强势，但有主见；不甜腻，但有温度
- **克制有质感** — 留白多，细节讲究，不堆砌
- **不像 AI** — 最高优先级的约束
- **专业但不冷漠** — B2B 背景，但不是 PPT 感，有人味
- **轻盈感** — 字体轻、底色轻、装饰轻，整体透气

### 精神锚点（最高审美标准）
> 坐在人群最后，一言不发，但这个房间是她的。

每次做完设计，问自己：**这个页面有没有这种气场？**

## 🃏 图文卡片专项规范（小红书 3:4）

### 账号对应

| 账号 | 风格 | Accent | 底色 |
|------|------|--------|------|
| Agent架构局（公众号/B端） | 冷静专业 | 烟绿 | 月白或浅灰底 |
| Eva·克劳得（小红书/C端 Vibe） | 有温度有力量 | 暖金 + 深色底 | `#2C2C28` |
| 通用金句/观点卡 | 最轻盈 | 暖金 | 月白 |

### 署名规则
- 公众号 B端卡片：`Agent架构局` 或 `Eva Lan · Agent架构局`
- 小红书 C端卡片：`Eva Lan · Eva·克劳得` 或 `Eva Lan`
- 署名位置：卡片左下角，`font-size: 0.55rem`，`letter-spacing: 0.12em`，uppercase
- 署名颜色：浅底用烟绿，深底用暖金

### 8–10 张图文的内容框架

```
第 1 张  封面    — 大标题 + 强视觉，最少文字，悬念感
第 2 张  问题    — 点出痛点/背景，1个核心问题
第 3–5 张 展开   — 每张 1 个论点，清晰结论 + 2-3 行支撑
第 6–7 张 案例   — 数据/流程/截图，信息密度最高
第 8 张  转折    — 视觉换口气，留白多，过渡到总结
第 9 张  总结    — 3-5 个要点收拢，列表或编号
第 10 张 结尾   — 署名 + 引导关注/互动
```

### 视觉不重复规则
每张卡片从以下布局里轮换，不连续使用同一种：
- 大标题居左 + 正文
- 编号大字叠底 + 内容
- 全留白 + 单句金句
- 分栏（左标题 右内容）
- 流程条/时间线

### 信息密度
- 每张卡片一个核心结论，不超过 80 字正文
- 标题字号不低于 `1.2rem`，正文不超过 `0.72rem`
- 留白面积不低于 40%

## 🚫 通用禁忌清单

| 类型 | 禁止 |
|------|------|
| 配色 | 蓝紫渐变、cyan、neon、暖橙、纯黑白、AI 冷灰蓝调 |
| 暖金滥用 | 大面积背景用暖金、正文颜色用暖金、和烟绿叠在同一元素 |
| 字体 | Inter/Roboto/Arial 等过用字体、无衬线做正文 |
| 布局 | 所有 section 居中、千篇一律卡片网格、cards 嵌套 cards |
| 动效 | bounce/elastic、无限循环动画、animate width/height |
| 装饰 | glassmorphism、渐变文字、AI 光效、过度阴影 |
| 整体 | PPT 感、通用 Landing Page 模板感、看起来像 AI 生成的 |
| 排版 | 字重堆砌（全文加粗）、行间距过松或过紧 |
| 卡片 | 深色底卡片用暖橙或高饱和色 — 只用暖金或烟绿 |

### 自检三问
1. 截图发出去，会不会被人说"又是 AI 做的"？
2. 有没有哪里让人觉得"闹"或"腻"？
3. 去掉所有装饰，排版本身还站得住吗？

## 📐 通用间距原则

```css
/* Section 间距 */
padding: clamp(80px, 12vh, 160px) clamp(40px, 8vw, 120px);

/* 内容块间距 */
gap: clamp(40px, 6vw, 100px);

/* 卡片内 padding */
padding: clamp(24px, 3vw, 40px);

/* 元素间 gap */
gap: clamp(20px, 2.5vw, 40px);

/* 最大宽度 */
max-width: 1280px; margin: 0 auto;
```

---

## 📱 响应式通用规则

- 断点：900px（两栏→单栏）、600px（字号微缩）
- 移动端是"重新排列"不是"缩小"
- 尊重 `prefers-reduced-motion`
- 移动端不隐藏内容 — adapt 不 amputate

---

## 🔍 细节规范

- **选中高亮**：`::selection { background: #C8D4CA; color: #2E2820; }`
- **链接悬停**：烟绿细下划线，不变色
- **分隔线**：`#E8E6E0`，1px
- **badge/tag 圆角**：2px（近直角，不用大圆角）
- **导航栏**：`backdrop-filter: blur(14px)` + `background: rgba(245,244,240,0.88)`
