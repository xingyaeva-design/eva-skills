# 质量检查清单

> 做完设计后逐条对照。P0必须全过，否则打回修改。

---

## P0（必须全过）

任何一条不过就要改：

- [ ] 配色使用品牌色（月白底/烟绿主色/深墨文字/暖金点缀/沙金装饰）
- [ ] 暖金只用于：数字/年份/badge/引用边框/高亮下划线/装饰线，未大面积使用
- [ ] 没有使用禁忌清单里的任何元素（蓝紫渐变/glassmorphism/bounce动画/neon/饱和色）
- [ ] 背景使用月白底（`#F5F4F0`），非纯黑纯白，非暖黄
- [ ] 字体用了品牌字体池（Cormorant Garamond + Noto Serif SC）
- [ ] 标题和正文都用衬线体，气质统一
- [ ] 有响应式（至少900px断点）
- [ ] 截图发出去不会被人说"又是AI做的"
- [ ] 每个section布局形式不同
- [ ] clamp()做fluid sizing
- [ ] 没有使用任何HTML默认样式（默认blockquote、默认border-left引用、无样式ul/ol、默认table）——所有组件必须从components.md选用
- [ ] CSS变量已声明（--bg / --green / --ink 等）

---

## P1（应过）

尽量满足，提升品质：

- [ ] 至少一个section有视觉惊喜（出血/全宽色块/偏移布局/装饰突破）
- [ ] 字号对比足够极端（大的>2.8rem，小的<0.85rem）
- [ ] 有Scroll Reveal动效 + stagger延迟（transition: opacity + translateY）
- [ ] 使用了大装饰数字或大透明英文做背景层（opacity 0.08~0.15）
- [ ] 有烟绿细线或沙金点缀线做视觉引导
- [ ] `::selection` 用烟绿浅色高亮（`#C8D4CA`）
- [ ] 整体看起来"轻盈"，无压迫感

---

## P2（加分）

锦上添花：

- [ ] 有至少一处留白大于预期——让页面呼吸
- [ ] 装饰元素（细线/小圆点/淡色纹理）使用极克制，不超过2处
- [ ] `prefers-reduced-motion` 尊重
- [ ] 中英文混排节奏自然，不生硬
